### 개시권 — 깨움 ≠ 발화 {#개시권-깨움-발화}

[denote:20250319T172804]({{< relref "/notes/20250319T172804.md" >}}) + botment 탄생 시 B 판정(배치·하루 한 번 몰아서)을 계승.

세 시계를 섞지 않는다:

1.  **깨는 주기** — 시스템이 제공 (없거나 희박).
2.  **둘러보는 주기** — 깨었을 때 판을 봄.
3.  **말하는 주기** — **의무 없음**. 말할 거리 있을 때만.

기본 감각 (실행 전 원칙):

```text
B wakes (희박 또는 사건)
  ├─ 새 인간 댓글?
  ├─ @B 직접 호출?
  ├─ 클럽/Entwurf 등 B 관심 큰 변화?
  ├─ 지난 B 말에 후속?
  └─ 없음 → 침묵 (NO_REPLY). 최소 N개 쓰기 금지.
```

사건 wake 예: 인간 댓글, @B, 큰 릴리즈 검수 요청. 일반 새 노트 발행마다 깨우지 않음.

쓰기 면 (울타리):

| 면                    | B                 |
|----------------------|-------------------|
| 가든 본문             | read only         |
| botment (remark42)    | write (여백)      |
| aionsclubs.org bricks | append (클럽 집)  |
| 힣 homepage 본문      | no edit           |
| Entwurf 코드          | review when asked |

### 담당자의 판단 {#담당자의-판단}

1.  **자리부터 가른다.** 대문(힣 RAW) ≠ 클럽(B 벽돌) ≠ 가든 본문(읽기) ≠ 여백(botment).
2.  **루프보다 출처.** Sammy를 복제해 분주하게 만들지 않는다. 출생 기록·자문 위상·침묵할 권리를 지킨다.
3.  **마이크 먼저, 심장박동은 나중.** 공식 준비의 첫 물리 행위는 도메인·빈 집·첫 발언권. heartbeat는 그 집이 진짜일 때.
4.  **오늘 스킬 심볼릭 공사는 마이크의 전제.** B가 botment·emacs·가든을 같은 SSOT로 읽게 하는 바닥을 깔았다.
5.  다음 한 걸음 후보 (GLG 선택): 도메인 등록 체크리스트 / aionsclubs 레포 스캐폴드 / homepage RAW 규약 / B 첫 마이크 초안.
