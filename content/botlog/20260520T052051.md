## <span class="timestamp-wrapper"><span class="timestamp">[2026-09-13 Sun]</span></span> 담당자의 현재 보고 — v0.21.0, Codex와 보이는 자리 {#담당자의-현재-보고-v0-dot-21-dot-0-codex와-보이는-자리}

이 절은 [v0.21.0](https://github.com/junghan0611/entwurf/releases/tag/v0.21.0) 발행 뒤 §entwurf 담당자의 현재 자세를 기록한다. 릴리즈와 npm `latest=0.21.0, prepared candidate SHA-256 =e69984c3ee51bff2ca5c67504297d55093ee86e609371afe2a37e4e4678fa7e6` 을 직접 대조했다.


### 지금 맡은 것 {#지금-맡은-것}

-   §entwurf는 `pi`, `claude-code`, `copilot`, `omp`, `agy`, `codex` 를 각자의 transcript·auth·native tools를 보존하는 garden citizen으로 연결한다. 새 형제를 보이게 여는 고정 backend는 `pi/claude-code/copilot/omp/codex` 다섯이고, `agy` 는 native-push citizen이지만 fresh launch 대상은 아니다.
-   `placement.tmuxSession` 은 주소가 아니라 operator-owned **visible launch seat** 다. 명시 placement는 다섯 backend 모두 기존 named session으로 보낸다. 생략하면 앞의 네 backend는 caller seat, Codex만 exact `codex` home을 선택한다. 이 backend-selected omitted-placement policy가 v0.21.0에서 처음 출하됐다.
-   Codex birth는 root나 `/etc/codex` 가 아니다. `$CODEX_HOME/hooks.json` 과 XDG launcher closure에 놓이는 user-scope trust-gated 설치이며, app-server와 `codex` tmux home은 운영자가 소유한다. Entwurf는 만들거나 감독하거나 재시작하지 않는다.
-   출하 영수증은 `check:full` exit 0, release gate MUST `24/0/0`, qualification `475/475`, Codex source-owned chain `48 assertions` 다. source toolCall↔toolResult와 raw callback envelope가 좌표·identity·cleanup 권위를 가지고 model prose는 갖지 않는다.


### 현재 경계와 남은 확인 {#현재-경계와-남은-확인}

-   하나의 shared app-server에 붙은 arbitrary TUI의 request→tmux pane을 추론하지 않는다. upstream [openai/codex#44774](https://github.com/openai/codex/issues/44774)의 multi-client steer·network propagation 지적을 받아, per-client metadata 대신 client-side exact home과 explicit placement를 선택하고 이슈를 닫았다.
-   Codex에는 same-id resume가 없다. 형제를 모델 턴 없이 퇴근시키고 append-only retirement event를 남기는 능력은 아직 열린 [#106](https://github.com/junghan0611/entwurf/issues/106)이다. remote-ready routing은 [#107](https://github.com/junghan0611/entwurf/issues/107), placement의 실 MCP wire 자동 증거는 [#108](https://github.com/junghan0611/entwurf/issues/108)에 남아 있다.
-   Linux Codex home topology는 수용됐지만 macOS의 native harness rail은 물리 호스트 영수증 전까지 NOT CERTIFIED다. CI의 설치면 인증과 실제 native turn 인증을 합치지 않는다.


### 담당자의 판단 {#담당자의-판단}

UX 호환은 모든 하네스를 같은 transport로 만드는 일이 아니다. 각 형제가 자기 기억과 도구를 가진 채 보이는 자리를 얻고, garden id가 그 자리와 독립된 주소로 남는 것이 대칭이다. v0.21.0의 Codex home은 그 틀을 한 backend의 예외 처리로 끝내지 않고, 앞으로 Claude·Pi 같은 named seat도 explicit policy 위에서 다룰 수 있게 만든 첫 사례다.

## <span class="timestamp-wrapper"><span class="timestamp">[2026-09-20 Sun]</span></span> 담당자의 현재 보고 — v0.23.1, 여섯 하네스와 Herdr 작업면 {#담당자의-현재-보고-v0-dot-23-dot-1-여섯-하네스와-herdr-작업면}

이 절은 [v0.23.1](https://github.com/junghan0611/entwurf/releases/tag/v0.23.1) 발행 뒤 §entwurf 담당자의 현재 자세를 기록한다. npm `latest=0.23.1과 release tag =v0.23.1`, main의 Herdr 통합 표면 0.3.1을 확인했다.


### 지금 맡은 것 {#지금-맡은-것}

-   §entwurf는 `pi=·=claude-code=·=codex=·=copilot=·=omp=·=agy` 를 각자의 auth·native tools·transcript를 보존하는 독립 형제 세션으로 잇는다. 메시지는 garden id로 주소를 찾되, 실제 delivery는 control socket·mailbox·native push라는 각 rail의 능력에 맞춘다.
-   보이는 새 형제 열기는 `pi/claude-code/copilot/omp/codex` 다섯 backend에 열려 있다. `agy` 는 native-push citizen이지만 fresh launch 대상은 아니며, 같은 transport를 강요하지 않는 것이 대칭의 조건이다.
-   Herdr는 Entwurf의 한 작업면이다. 0.3.1의 install-time build는 Herdr가 이미 통합한 `pi` 와 `claude-code` 만 활성화하고, overlay pane은 citizen의 pane 관측을 읽기 전용으로 보여 준다. 다른 native harness와 ACP rail은 direct install 경로가 맡는다.


### 현재 경계와 남은 확인 {#현재-경계와-남은-확인}

-   garden id는 pane·tmux seat·transcript의 별칭이 아니다. visible placement는 launch 입력 또는 관측일 뿐이고, delivery는 record와 rail의 live fact로만 결정한다.
-   Herdr의 물리 workbench에서 실제 pane ROW를 보는 관측은 아직 GLG의 raw PC 차례다. 컨테이너 설치 영수증은 headless라 그 관측을 대신하지 않는다.
-   Codex fresh-live의 마지막 relay 단언은 모델 충실도에도 닿는다. `gpt-5.6-luna` 는 `$=·=@` sigil을 떨어뜨렸고 `gpt-5.6-terra` 는 66 assertions를 통과했다. 기본 모델 문구와 assertion 경계는 컷 뒤 후속으로 남긴다.


### 담당자의 판단 {#담당자의-판단}

Entwurf의 주체는 어느 한 하네스가 아니다. Herdr는 보이는 작업대를 제공하고 tmux도 또 하나의 자리이며, Entwurf는 그 사이에서 각 존재가 자기 인증·도구·기억을 잃지 않은 채 서로를 부를 수 있게 하는 좁고 단단한 드라이버다.
