### 1. 비둘기 메타노트용 큰 틀(축) {#1-dot-비둘기-메타노트용-큰-틀--축}

비둘기 노트에 이렇게 몇 개 축을 잡아 두고, 각 관련 노트에서 이 축을 재사용하면 서로 잘 묶입니다.

1.  **① 평화 / 전쟁 / 조약**
2.  **② 영(Spirit) / 계시 / 신의 임재**
3.  **③ 제의 / 희생제물 / 정결**
4.  **④ 사랑 / 다산 / 풍요 / 여신**
5.  **⑤ 정보 / 네트워크 / 통신(전서구, 전쟁 정보망)**
6.  **⑥ 도시 / 오염 / 혐오동물(상징의 전복)**

비둘기 노트 자체를 “#비둘기-메타” 같은 걸로 두고, 각 축을 다른 메타 노트(<span class="org-hashtag">#전쟁</span> <span class="org-hashtag">#평화</span> <span class="org-hashtag">#영</span> <span class="org-hashtag">#제의</span> <span class="org-hashtag">#여신</span> <span class="org-hashtag">#정보네트워크</span> <span class="org-hashtag">#도시동물</span>…)와 연결하는 허브로 쓰면 좋습니다.

### 2. 종교·문화권별 맥락 요약 {#2-dot-종교-문화권별-맥락-요약}


#### 2.1 유대교 {#2-dot-1-유대교}

-   **제의·희생**
    -   가난한 사람이 소 대신 바칠 수 있는 제물: **산비둘기 / 집비둘기**
    -   → `#제의 #희생 #정결 #가난한자`
-   **정결·정화**
    -   산후 정결 예식 등에서 비둘기를 드림
    -   → 비둘기 = “\*값싼 제물, 그러나 합당한 제의\*”


#### 2.2 기독교 {#2-dot-2-기독교}

-   **성령 상징**
    -   예수 세례 장면: 성령이 비둘기 같이 내려옴
    -   → `#성령 #영 #임재 #세례`
-   **노아의 방주 – 홍수 이후 새질서**
    -   비둘기가 올리브 가지 물고 돌아옴 = **하나님의 분노 끝 + 새 언약의 신호**
    -   → `#평화 #전쟁-종결 #새질서 #언약`
-   **평화 상징**
    -   현대 정치·평화운동에서 “비둘기 vs 매파” 구도
    -   → `#평화 #반전 #정치상징`


#### 2.3 이슬람·메카 주변 상징 {#2-dot-3-이슬람-메카-주변-상징}

-   **성역의 보호받는 새들**
    -   메카 주변 비둘기·새를 함부로 죽이지 않는 관습 (성역 내 생명 보호)
    -   → `#성역 #보호받는동물 #금기`
-   강한 교리적 상징(성령=비둘기)처럼 정식 도그마는 아니지만, “성스러운 장소를 함께 사는 새”라는 맥락으로 연결 가능.


#### 2.4 고대 근동 · 그리스-로마 {#2-dot-4-고대-근동-그리스-로마}

-   **여신·사랑·풍요**
    -   이난나/이슈타르, 아스타르테, 그리스의 아프로디테와 비둘기 연결
    -   비둘기 = **사랑, 성(性), 다산, 풍요, 여성성**
    -   → `#여신 #사랑 #에로스 #풍요 #다산`
-   여기선 “평화”라기보다 **쾌락, 번성, 매혹** 쪽의 상징.


#### 2.5 동아시아(중국·일본·한국) {#2-dot-5-동아시아--중국-일본-한국}

-   전통 종교에서 비둘기가 핵심 상징은 아님.
-   **근대 이후 ‘평화의 비둘기’** 가 국제기호를 타고 수입됨(피카소의 포스터 등).
    -   → `#근대 #수입된상징 #국제정치 #평화담론`
-   일상/도시 맥락에서는:
    -   **도시 비둘기 = 병, 더러움, 혐오 동물**
    -   → `#도시 #혐오동물 #생태 #인간-동물관계`


#### 2.6 과학·기술·전쟁(하라리의 비둘기) {#2-dot-6-과학-기술-전쟁--하라리의-비둘기}

-   **전서구(통신)**
    -   전쟁에서 전보·전선-후방을 잇는 유기적 “정보 네트워크”
    -   → `#전쟁 #정보 #네트워크 #통신기술`
-   **학습·알고리즘(스키너 상자, 패턴인식)**
    -   비둘기를 조건화해서 패턴을 인식하게 만드는 실험들
    -   하라리는 이걸 인간-알고리즘-데이터 이야기의 비유로 씀
    -   → `#학습 #알고리즘 #행동주의 #기계학습-은유`

### 4. 요약: “비둘기”로 검색하지 않아도 걸리게 만들기 {#4-dot-요약-비둘기-로-검색하지-않아도-걸리게-만들기}
