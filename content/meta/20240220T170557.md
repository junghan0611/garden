### Tiling window manager {#tiling-window-manager}

(<a href="#citeproc_bib_item_3">“Tiling Window Manager,” 2025</a>) 2025

In computing, a tiling window manager is a window manager with the organization of the screen often dependant on mathematical formulas to organise the windows into a non-overlapping frame. This is opposed to the more common approach used by stacking window managers, which allow the user to drag windows around, instead of windows snapping into a position. This allows for a different style of organization, although it departs from the traditional desktop metaphor.

컴퓨팅에서 타일링 창 관리자는 화면 구성을 수학 공식에 의존하여 창을 겹치지 않는 프레임으로 구성하는 창 관리자입니다. 이는 창을 위치에 고정하는 대신 사용자가 창을 끌어서 이동할 수 있는 스택 창 관리자에서 사용하는 일반적인 방식과 반대입니다. 이는 전통적인 데스크톱 비유에서 벗어나지만 다른 스타일의 구성을 허용합니다.


### X Window System {#x-window-system}

(<a href="#citeproc_bib_item_4">“X Window System,” 2025</a>) 2025

The X Window System (X11, or simply X) is a windowing system for bitmap displays, common on Unix-like operating systems. X originated as part of Project Athena at Massachusetts Institute of Technology (MIT) in 1984. The X protocol has been at version 11 (hence "X11") since September 1987. The X.Org Foundation leads the X project, with the current reference implementation, X.Org Server, available as free and open-source software under the MIT License and similar permissive licenses.

X 윈도우 시스템(X11 또는 간단히 X)은 유닉스 계열 운영 체제에서 흔히 볼 수 있는 비트맵 디스플레이용 윈도우 시스템입니다. X는 1984년 매사추세츠 공과대학(MIT)의 프로젝트 아테나에서 시작되었습니다. X 프로토콜은 1987년 9월부터 버전 11(이하 "X11")로 유지되고 있습니다. X.Org 재단은 현재 참조 구현인 X.Org 서버를 MIT 라이선스와 유사한 허용 라이선스에 따라 무료 오픈 소스 소프트웨어로 제공하는 X 프로젝트를 주도하고 있으며, 이 소프트웨어는 MIT 라이선스와 유사한 허용된 라이선스에 따라 제공됩니다.


### i3 (window manager) {#i3--window-manager}

(<a href="#citeproc_bib_item_1">“I3 (Window Manager),” 2024</a>) 2024

i3 is a tiling window manager designed for X11, inspired by wmii and written in C. It supports tiling, stacking, and tabbing layouts, which are handled manually. Its configuration is achieved via a plain text file and extending i3 is possible using its Unix domain socket and JSON based IPC interface from many programming languages. Like wmii, i3 uses a control system very similar to that of vi and Vim. By default, window focus is controlled by what the documentation refers to as the 'Mod1' key (Alt key/Windows key) in addition to the right-hand home row keys (Mod1+J,K,L,Semicolon), while window movement is controlled by the addition of the Shift key (Mod1+Shift+J,K,L,Semicolon).

i3는 X11용으로 설계된 타일링 창 관리자로, wmii에서 영감을 받아 C로 작성되었으며 타일링, 스태킹 및 탭 레이아웃을 지원하고 수동으로 처리됩니다. 구성은 일반 텍스트 파일을 통해 이루어지며 다양한 프로그래밍 언어의 Unix 도메인 소켓 및 JSON 기반 IPC 인터페이스를 사용하여 i3를 확장할 수 있습니다. wmii처럼 i3는 vi 및 Vim과 매우 유사한 제어 시스템을 사용합니다. 기본적으로 창 초점은 문서에서 'Mod1' 키(Alt 키/Windows 키) 외에 오른쪽 홈 행 키(Mod1+J,K,L,세미콜론)로 제어되고 창 이동은 Shift 키 추가(Mod1+Shift+J,K,L,Semicolon) 기능을 통해 제어할 수 있습니다.


### Sway (window manager) {#sway--window-manager}

(<a href="#citeproc_bib_item_2">“Sway (Window Manager),” 2025</a>) 2025

Sway는 i3에서 영감을 받아 C로 작성된 타일링 창 관리자이자 Wayland 컴포지터로, 보다 현대적인 Wayland 디스플레이 서버 프로토콜과 wlroots 컴포지터 라이브러리를 사용하여 i3를 드롭인 방식으로 대체할 수 있도록 설계되었습니다. Sway는 기존 i3 구성 파일과 함께 작동하며 i3의 대부분의 기능을 지원하는 동시에 자체적으로 몇 가지 새로운 기능을 제공합니다. 창을 조작하기 위한 Sway의 기본 컨트롤은 vi와 유사합니다. 창 초점은 수퍼 키와 화살표 키 또는 h, j, k, l 중 하나의 조합으로 제어되며, 창 이동은 동일한 키 조합에 Shift 키를 추가하여 수행됩니다. I3와 마찬가지로 Sway는 다양한 프로그래밍 언어의 Unix 도메인 소켓과 JSON 기반 IPC 인터페이스를 사용하여 확장 및 조작할 수 있습니다. 3.6년간의 개발 끝에 2019년 3월 11일에 Sway가 처음으로 안정적으로 출시되었습니다

Sway is a tiling window manager and Wayland compositor, inspired by i3, and written in C. Sway is designed as a drop-in replacement for i3 using the more modern Wayland display server protocol and wlroots compositor library. Sway works with existing i3 configuration files and supports most of i3's features while providing several new features of its own. Sway's default controls for manipulating windows are similar to vi. Window focus is controlled by a combination of the Super key and one of the arrow keys or h, j, k, and l. Window movement is performed by the same combination of keys with the addition of the shift key. Like i3, Sway can be extended and manipulated using its Unix domain socket and JSON-based IPC interface from many programming languages. Sway's first stable release was on March 11, 2019, after 3.6 years of development.

Sway는 i3에서 영감을 받아 C로 작성된 타일링 창 관리자이자 Wayland 컴포지터로, 보다 현대적인 Wayland 디스플레이 서버 프로토콜과 wlroots 컴포지터 라이브러리를 사용하여 i3를 드롭인 방식으로 대체할 수 있도록 설계되었습니다. #### @user i3wm, sway와 같은 타일링 윈도우 매니저를 정의하고 관련 프로젝트를 소개해줘 {#user-i3wm-sway와-같은-타일링-윈도우-매니저를-정의하고-관련-프로젝트를-소개해줘}

@assistant \*\*타일링 윈도우 매니저\*는 화면을 타일 형태로 나누어 윈도우를 배치하는 방식으로, 중첩 없이 공간을 효율적으로 활용합니다. 대표적인 타일링 윈도우 매니저로는 \*i3wm\*과 \*Sway\*가 있습니다.


##### i3wm {#i3wm}

-   \*i3wm\*은 리눅스에서 인기 있는 타일링 윈도우 매니저로, 키보드 중심의 사용자 인터페이스를 제공합니다. 사용자는 키보드 단축키를 통해 윈도우를 쉽게 관리할 수 있습니다[2][3][5].
-   \*Regolith Linux\*는 i3wm을 기본으로 한 우분투 기반 배포판으로, i3wm의 복잡한 설정을 간소화하여 사용자에게 편리한 환경을 제공합니다[2].


##### Sway {#sway}

-   \*Sway\*는 Wayland 프로토콜을 지원하는 타일링 윈도우 매니저로, i3wm의 기능을 Wayland 환경에서 활용할 수 있도록 설계되었습니다.
-   Sway는 i3wm과 유사한 사용자 인터페이스를 제공하며, Wayland의 장점을 활용하여 더 나은 성능과 보안을 제공합니다.

이 외에도 \*StumpWM\*과 같은 다른 타일링 윈도우 매니저도 존재하며, 각기 다른 특징과 사용법을 가지고 있습니다.

##### 타일링 윈도우 매니저의 종류 및 특징 {#타일링-윈도우-매니저의-종류-및-특징}

-   **i3**: 키보드 중심의 사용법, 효율적인 창 관리, Regolith Linux와 함께 사용하기 좋습니다[2].
-   **Sway**: Wayland 기반, i3와 유사한 사용법, 모바일 환경에서도 사용됩니다[3].
-   **AwesomeWM**: 동적 타일링, 상태바와 런처 기능을 제공합니다[3].
-   **DWM**: 직접 소스코드 수정이 가능하며, 매우 가벼운 리소스 사용량을 특징으로 합니다[3].


##### 타일링 윈도우 매니저의 장단점 {#타일링-윈도우-매니저의-장단점}

-   **장점**: 창을 겹치지 않고 효율적으로 배치하여 멀티태스킹에 유리합니다.
-   **단점**: 초기 설정이 복잡할 수 있으며, 사용자에게 익숙해지기까지 시간이 걸릴 수 있습니다.
