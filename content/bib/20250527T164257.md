## 코드 읽기: 오픈소스 관점 Code Reading: The Open Source Perspective {#코드-읽기-오픈소스-관점-code-reading-the-open-source-perspective}

(<a href="#citeproc_bib_item_1">Diomidis Spinellis 2004</a>) Diomidis Spinellis 류광 2004

코드 읽기는 고유한 기술들이 필요한, 그리고 언제 어떤 기법을 사용해야 할 지 판단하는 능력이 중요한 활동이다. 저자 Diomidis Spinellis는 600 개 이상의 실제 예제들을 통해서 좋은(그리고 나쁜) 코드를 식별하는 법, 그것을 읽는 법, 중요한 부분을 찾는 법, 그리고 그러한 지식을 가지고 독자 자신의 코드를 개선시키는 법을 보여준다.

-   1.1 코드를 왜, 어떻게 읽어야 하나
-   1.2 이 책을 읽는 방법
-   더 읽을거리

-   2.2 함수와 전역 변수

-   2.4 switch 문
-   2.5 for 루프
-   2.6 break 문과 continue 문
-   2.7 문자와 부울 표현식
-   2.8 goto 문
-   2.9 작은 규모의 리팩토링
-   2.10 do 루프와 정수 표현식
