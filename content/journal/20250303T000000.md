#### kickingvegas/recent-rgrep {#kickingvegas-recent-rgrep}

(Choi [2025] 2025)

-   Choi, Charles
-   Bash script and Elisp command to return recursive grep result sorted by recently modified file descending.


#### Summary {#summary}

최근 Charles Choi가 개발한 recent-rgrep는 Emacs에서 파일 검색을 더 효율적으로 하도록 돕는 새로운 도구입니다.

주요 기능은 다음과 같습니다:

1 최근 수정된 파일부터 검색 결과를 보여줍니다.

2 바이너리 파일은 제외하고 검색합니다.

3 .git, .hg, .svn, .cvs 등 버전관리 시스템 디렉토리는 자동으로 제외합니다.

4 시스템에 설치된 기존 grep 명령어를 사용합니다.

5 기본적으로 대소문자 구분 없이 검색합니다.

6 명령줄과 Emacs 모두에서 사용 가능합니다.

ripgrep을 이미 사용하고 있다면, recent-rgrep은 불필요할 수도 있습니다. 하지만 ripgrep이 없는 경우 유용하게 사용할 수 있습니다. 두 번의 패스를 수행하여 성능 저하가 발생할 수 있지만, 실제 사용 시 큰 문제는 없다고 합니다.

관련 기사는 여기에서 확인할 수 있습니다.
