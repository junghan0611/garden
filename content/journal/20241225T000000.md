> Appearance Font and Font Size Scaling My default font is “Hack” or “Meslo”. I also use “WenQuanYi Micro Hei” for Chinese, Japanese, and Korean characters (CJK) and “Noto Color Emoji” for emojis.
>
> Different fonts can have different widths and heights, even when they are the same size. For example, size 10 of font A might be bigger than size 10 of font B. This can make things look uneven. I rescale the font with face-font-rescale-alist so that they have the same width (I might get the same height if I am lucky). This makes things look better, especially in tables in org mode.

```elisp
;; https://whhone.com/emacs-config/
(defun my/set-fonts (default-font-name
                     default-font-height
                     cjk-font-name
                     cjk-font-scale
                     emoji-font-name
                     emoji-font-scale)
  "Helper function to set the default, CJK and Emoji fonts."
  ;; Set the default font
  (when (member default-font-name (font-family-list))
    (set-face-attribute 'default nil
                        :family default-font-name
                        :height default-font-height)
    (set-frame-font default-font-name nil t))

  ;; Set the CJK font in the default fontset.
  (when (member cjk-font-name (font-family-list))
    (dolist (script (list 'han 'kana 'cjk-misc))
      (set-fontset-font t script cjk-font-name)))

  ;; Set the Emoji font in the default fontset.
  (when (member emoji-font-name (font-family-list))
    (set-fontset-font t 'emoji emoji-font-name))

  ;; Rescale the CJK and emoji fonts.
  (setq face-font-rescale-alist
        `((,(format ".*%s.*" cjk-font-name) . ,cjk-font-scale)
          (,(format ".*%s.*" emoji-font-name) . ,emoji-font-scale))))

;; Different computers might need different scaling factors with the
;; same fonts.
(cond
 ;; MacOS, HiDPI
 ((eq system-type 'darwin)
  (my/set-fonts
   "Menlo" 140
   "Hiragino Sans CNS" 1.2
   "Apple Color Emoji" 0.9))
 ;; Default Linux
 (t
  (my/set-fonts
   "Source Code Pro" 100
   ;; "Hack" 100
   "WenQuanYi Micro Hei" 1.25
   "Noto Color Emoji" 1.00)))
```

유용한 유니코드 노트테이킹

```elisp

(progn
  (setq my/unicode-notetaking '( "" "§" "¶" "†" "‡" "№" "※" "☞"))

  (defun my/insert-unicode-notetaking ()
    "Insert Unicode for NoteTaking."
    (interactive)
    (insert (completing-read "Select category: " my/unicode-notetaking))
  ;; (evil-define-key '(insert normal) text-mode-map (kbd "M-m") #'my/insert-unicode-notetaking))
  )

```

0x002020 † DAGGER 0x002021 ‡ DOUBLE DAGGER 0x002E4B ⹋ TRIPLE DAGGER

-   **§** (Section Sign, 0x0000A7)
-   **¶** (Pilcrow Sign, 유니코드 U+00B6): 문단의 시작을 표시하거나, 문서의 구조를 나타내는 데 사용됩니다. 법률 문서나 학술 문서에서 문단을 구분할 때 흔히 볼 수 있습니다.

-   **‡** (Double Dagger, 유니코드 U+2021): 주석이나 참조를 나타낼 때 사용됩니다. 단일 다거(†)와 함께 사용되어, 문서에서 특정 부분을 참조하거나 설명할 때 유용합니다.

-   **№** (Numero Sign, 유니코드 U+2116): 숫자와 함께 사용되어, "번호"를 의미합니다. 예를 들어, "№ 123"은 "123번"을 의미합니다.

-   **※** (Reference Mark, 유니코드 U+203B): 일본어 문서에서 주로 사용되며, 참조나 주석을 표시하는 데 사용됩니다.

-   **☞** (Pointing Index, 유니코드 U+261E): 특정 부분을 강조하거나 주목하도록 유도할 때 사용됩니다.

이러한 기호들은 문서의 구조를 명확히 하거나, 특정 부분을 참조하는 데 유용하게 사용됩니다. 문서 작성 시, 이러한 기호들을 적절히 활용하면 문서의 가독성과 이해를 돕는 데 도움이 될 수 있습니다.

-   _알파벳_: A-Z, a-z
-   _숫자_: 0-9
-   _특수문자_: 공백( ), 하이픈(-), 언더스코어(_), 마침표(.), 대시(—), 아포스트로피('), 괄호(()) 등
-   _한글_: 가-힣
-   _일본어_: ひらがな, カタカナ, 한자(漢字)
-   _중국어_: 汉字(한자)
-   _이모지_: 😊, 🌟 등 (운영 체제와 파일 시스템에 따라 제한이 있을 수 있음)

하지만 파일명에 사용할 수 없는 문자들도 있습니다:

-   /역슬래시(\\)\*: 경로 구분자로 사용되므로 파일명에 사용 불가
-   _슬래시(_) or (:)\*: 경로 구분자로 사용되므로 파일명에 사용 불가
-   /물음표(?) or 별표(**)**: 와일드카드로 사용되므로 파일명에 사용 불가
-   /큰따옴표(")\*: 파일명에 사용 불가
-   /파이프(|)\*: 명령어 파이프로 사용되므로 파일명에 사용 불가
-   /꺽쇠(&lt;, &gt;)\*: 파일명에 사용 불가
-   /콜론(:)\*: Windows에서는 파일명에 사용 불가
-   /세미콜론(;)\*: 파일명에 사용 불가

또한, 파일명의 길이에도 제한이 있을 수 있습니다. 예를 들어, Windows에서는 파일명이 255자 이하여야 하고, macOS에서는 255 UTF-16 코드 유닛 이하여야 합니다.

파일명에 사용할 수 있는 유니코드 문자는 매우 다양하지만, 특정 문자나 기호는 파일 시스템이나 운영 체제에 따라 제한이 있을 수 있으므로, 파일명을 지정할 때는 주의가 필요합니다.

@assistant 브라우저에서 유니코드 문자를 쉽게 입력하는 몇 가지 방법이 있습니다:

1.  **유니코드 입력기 사용**: 웹 브라우저의 확장 프로그램이나 웹사이트에서 제공하는 유니코드 입력기를 사용할 수 있습니다. 예를 들어, "Unicode Input" 같은 확장 프로그램을 설치하면 유니코드 문자를 쉽게 입력할 수 있습니다.

2.  **유니코드 코드 포인트 입력**: 유니코드 코드 포인트를 직접 입력할 수 있습니다. 예를 들어, '§' 기호는 U+00A7이므로, 다음과 같이 입력할 수 있습니다:
    -   Windows: `Alt` 키를 누른 상태에서 숫자 키패드를 사용하여 =0167=을 입력합니다.
    -   macOS: `Option` 키를 누른 상태에서 `6` 키를 누릅니다.

3.  **유니코드 입력기 웹사이트 사용**: 유니코드 문자를 쉽게 입력할 수 있는 웹사이트를 사용할 수 있습니다. 예를 들어, "Unicode Character Table" 같은 사이트에서 원하는 문자를 찾아 복사하여 붙여넣기 할 수 있습니다.

4.  **자동 완성 기능**: 일부 브라우저에서는 자동 완성 기능을 통해 유니코드 문자를 입력할 수 있습니다. 예를 들어, Google Chrome에서는 `Ctrl` + `Shift` + =U=를 누른 후 유니코드 코드 포인트를 입력하면 해당 문자가 나타납니다.

5.  **입력기 변경**: Windows에서는 "입력기"를 변경하여 특정 언어의 문자를 입력할 수 있습니다. 예를 들어, 한국어 입력기를 사용하면 한글을 쉽게 입력할 수 있습니다.

6.  **단축키 사용**: 일부 브라우저에서는 특정 단축키를 통해 유니코드 문자를 입력할 수 있습니다. 예를 들어, Firefox에서는 `Ctrl` + `Shift` + =U=를 누른 후 유니코드 코드 포인트를 입력하면 됩니다.

이러한 방법들을 사용하여 브라우저에서 유니코드 문자를 쉽게 입력할 수 있습니다. 필요에 따라 가장 편리한 방법을 선택하여 사용하면 됩니다.

@user 리눅스에서는?

@assistant 리눅스에서는 유니코드 문자를 입력하는 몇 가지 방법이 있습니다:

1.  _유니코드 입력기 사용_: 리눅스에서도 유니코드 입력기를 사용할 수 있습니다. 예를 들어, GNOME 데스크탑 환경에서는 "Character Map"을 사용하여 유니코드 문자를 찾아 복사하여 붙여넣기 할 수 있습니다.

2.  _유니코드 코드 포인트 입력_: 리눅스에서는 다음과 같은 방법으로 유니코드 코드 포인트를 입력할 수 있습니다:
    -   `Ctrl` + `Shift` + `U=를 누른 후 유니코드 코드 포인트를 입력합니다. 예를 들어, '§' 기호는 U+00A7이므로, =Ctrl` + `Shift` + =U=를 누른 후 =00A7=을 입력하면 됩니다.

3.  _입력기 변경_: 리눅스에서는 다양한 입력기를 사용하여 특정 언어의 문자를 입력할 수 있습니다. 예를 들어, 한국어 입력기를 사용하면 한글을 쉽게 입력할 수 있습니다.

4.  _단축키 사용_: 일부 데스크탑 환경에서는 특정 단축키를 통해 유니코드 문자를 입력할 수 있습니다. 예를 들어, GNOME에서는 `Ctrl` + `Shift` + =U=를 누른 후 유니코드 코드 포인트를 입력하면 됩니다.

5.  _유니코드 입력기 웹사이트 사용_: 웹사이트를 통해 유니코드 문자를 찾아 복사하여 붙여넣기 할 수 있습니다. 예를 들어, "Unicode Character Table" 같은 사이트를 사용할 수 있습니다.

6.  _터미널에서 유니코드 입력_: 터미널에서 유니코드 문자를 입력하려면, =echo -e '\u00A7'=와 같이 명령어를 사용하여 유니코드 문자를 출력할 수 있습니다.

리눅스에서는 다양한 방법으로 유니코드 문자를 입력할 수 있으며, 사용 중인 데스크탑 환경이나 터미널에 따라 다를 수 있습니다. 필요에 따라 가장 편리한 방법을 선택하여 사용하면 됩니다.
