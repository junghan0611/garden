## [2025-02-07 W05]({{< relref "/journal/20250203T000000.md" >}}) {#2025-02-07-w05--relref-journal-20250203t000000-dot-md}

@user 클로저 개발 환경 중에서 이맥스가 가지는 장점은?

@assistant 이맥스(Emacs)는 클로저 개발 환경에서 여러 장점을 제공합니다:

1.  **고급 에디터 기능**: 이맥스는 강력한 에디터 기능을 제공하며, 코드 작성, 디버깅, 프로젝트 관리에 유용합니다.
2.  **CIDER 및 기타 플러그인 지원**: CIDER와 같은 플러그인을 통해 클로저 코드의 REPL, 디버깅, 코드 완성 기능을 활용할 수 있습니다.
3.  **다중 창 및 버퍼 관리**: 여러 파일과 프로젝트를 동시에 관리할 수 있어 생산성을 높입니다.
4.  **키보드 중심의 인터페이스**: 이맥스는 키보드 중심의 인터페이스를 제공하여 마우스 사용을 최소화하고 효율적인 작업이 가능합니다.

이러한 기능들은 개발자들이 이맥스를 선호하는 이유 중 하나입니다.

@user Cider의 장점은?

@assistant CIDER의 장점은 다음과 같습니다:

1.  **스마트 코드 완성 및 문서 검색**: CIDER는 Clojure와 ClojureScript에 대한 스마트 코드 완성과 문서 검색 기능을 제공합니다[1][2].
2.  **강력한 디버깅 기능**: CIDER는 Edebug에서 영감을 받은 강력한 소스 코드 디버거를 포함하고 있습니다[1].
3.  **REPL 경험**: CIDER는 다양한 기능을 갖춘 REPL 경험을 제공하며, 코드를 평가하고 결과를 바로 확인할 수 있습니다[1][5].
4.  **테스트 실행**: CIDER를 사용하면 에디터에서 테스트를 실행할 수 있어 개발 효율성을 높일 수 있습니다[1].

Citations: [1] <https://cider.mx> [2] <https://github.com/clojure-emacs/cider> [3] <https://groups.google.com/g/clojure-kr/c/IKmn3QG1ojY> [4] <https://groups.google.com/g/lisp-korea/c/i4FJXX143jw> [5] <https://www.karimarttila.fi/clojure/2021/01/27/clojure-emacs-vs-cursive.html>

@user 클로저 개발 환경으로서 이맥스가 지니는 장점은? Cider를 중심으로 분석해줘

@assistant 이맥스+CIDER 조합의 클로저 개발 환경 장점을 다음과 같이 분석합니다:

1.  **통합 개발 경험**
    -   CIDER는 이맥스 내에서 REPL 통합/디버깅/테스트 실행을 원활히 수행 (cider-jack-in으로 프로젝트별 REPL 자동 구성)[1][5]
    -   코드 버퍼와 REPL 간 실시간 상호작용 가능 (eval-in-repl 기능)

2.  **동적 개발 사이클**
    -   <span class="underline">코드 핫 리로딩</span> 지원으로 런타임 중 코드 수정 즉시 반영[3]
    -   인라인 평가 결과 표시(cider-eval-last-sexp)로 즉각적 피드백

3.  **정밀 분석 도구**
    -   clj-kondo 정적 분석기 통합으로 코드 품질 관리[2]
    -   namespace 트리 시각화(ns-tree)를 통한 의존성 분석

4.  **확장 생태계**
    -   clj-refactor 모드로 리팩토링 자동화[4]
    -   Proto REPL/Gorilla과 연계한 데이터 시각화 지원

5.  **커스터마이징 잠재력**
    -   이맥스 Lisp으로 CIDER 확장 가능
    -   paredit+rainbow-delimiters 조합으로 구조적 편집 최적화

CIDER는 이맥스의 확장성을 기반으로 클로저의 동적 특성을 최대한 활용하는 통합 개발 경험을 제공합니다. 특히 REPL 중심 개발 패러다임과의 시너지가 두드러집니다.
