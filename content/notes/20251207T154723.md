## Emacs + Claude Code + 음성제어 워크플로우 구축 {#emacs-plus-claude-code-plus-음성제어-워크플로우-구축}


### 배경 {#배경}

Claude Code 정액제를 사용하면서 gptel을 잘 안 쓰게 됨. Emacs에서 Claude를 활용하고 싶은데, 터미널 기반 도구들은 한글 입력이 불편함.


### 조사한 패키지들 {#조사한-패키지들}


#### Emacs Claude Code 통합 패키지 비교 {#emacs-claude-code-통합-패키지-비교}

| 패키지               | 스타 | 프로토콜 | 특징                        |
|-------------------|----|------|---------------------------|
| agent-shell          | 377 | ACP     | xenodium 개발, shell-maker 기반 |
| ai-code-interface.el | 70  | CLI 래핑 | 워크플로우 통합, Org 프롬프트 관리 |
| eca-emacs            | 237 | JSONRPC | Eric Dallo 개발, LSP 스타일 |
| claude-code-ide.el   | -   | MCP     | 양방향 브릿지               |


#### 선택: ECA (Editor Code Assistant) {#선택-eca--editor-code-assistant}

-   gfm-view-mode 기반 → 한글 입력 문제 없음 (comint 아님!)
-   Claude Max OAuth 지원
-   MCP 서버 연동 지원
-   Eric Dallo (clojure-lsp 개발자) 품질

### Whisper.el 음성 입력 {#whisper-dot-el-음성-입력}


#### 모드 선택 {#모드-선택}

| 모드             | 설명                  | 비용            |
|----------------|---------------------|---------------|
| 로컬 (whisper.cpp) | CPU 오프라인          | 무료            |
| Groq API         | 클라우드 whisper-large-v3 | 무료 (rate limit) |
| OpenAI API       | gpt-4o-transcribe     | $0.006/분       |


#### 선택: Groq API {#선택-groq-api}

-   무료
-   로컬 설치 불필요 (ffmpeg만 필요)
-   한국어 CER ~11% (충분히 사용 가능)


#### 한국어 ASR 벤치마크 (AI-Hub 기준) {#한국어-asr-벤치마크--ai-hub-기준}

| 순위 | 모델                       | 평균 CER |
|----|--------------------------|--------|
| 1  | Return Zero                | 5.91%  |
| 2  | Return Zero Whisper (파인튜닝) | 6.59%  |
| 3  | Naver ClovaSpeech          | 7.52%  |
| 5  | OpenAI Whisper large-v3    | 11.39% |


### Elisp 설정 {#elisp-설정}

설정 파일: ~/sync/emacs/emacs-fulllab-config/+ai-eca-whisper.el


#### 핵심 설정 {#핵심-설정}

```elisp
;; Whisper - Groq API
(setq whisper-server-mode 'openai
      whisper-openai-api-baseurl "https://api.groq.com/openai/"
      whisper-openai-api-key (lambda ()
                               (string-trim
                                (shell-command-to-string "pass api/groq/junghanacs")))
      whisper-openai-model "whisper-large-v3"
      whisper-language "ko")

;; ECA
(setq eca-chat-window-side 'right
      eca-chat-window-width 0.45
      eca-chat-use-side-window t)
```


#### 키바인딩 {#키바인딩}

|--------|--------------|
| SPC v w | 음성 녹음 시작/중지 |
| SPC a e | ECA 시작       |
| SPC a v | ECA + 음성 입력 통합 |


### 해결한 문제들 {#해결한-문제들}


#### ANTHROPIC_API_KEY 환경변수 충돌 {#anthropic-api-key-환경변수-충돌}

ECA가 OAuth 대신 API 키를 먼저 사용하려고 함.

해결:

-   ~/.spacemacs.env에서 ANTHROPIC_API_KEY 제거
-   ~/.cache/eca/ 캐시 삭제 후 재로그인


### 아키텍처 요약 {#아키텍처-요약}

```text

└─────────────────────────────────────────────────────┘
```
