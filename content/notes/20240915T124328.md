## 스냅 패키지는 다 삭제하라. 공간 확보. {#스냅-패키지는-다-삭제하라-dot-공간-확보-dot}

```shell

ncdu /snap

sudo snap remove celestia-daily
sudo snap remove telegram-desktop
sudo snap remove firefox
sudo snap remove gnome-42-2204

```

```text
sudo snap install emacs --classic
```
