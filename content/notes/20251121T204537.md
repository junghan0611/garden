## Claude Code &amp; OpenCode 에이전트 통합 구성 {#claude-code-and-opencode-에이전트-통합-구성}


### 개요 {#개요}

Claude Code와 OpenCode에서 사용할 전문 에이전트 시스템을 일관성 있게 구성했습니다. 총 12개의 에이전트를 개발 라이프사이클 전반을 커버하도록 설계했으며, 각 플랫폼의 양식에 맞춰 동일한 에이전트 세트를 적용했습니다.


### 에이전트 구성 철학 {#에이전트-구성-철학}


#### 명확한 역할 분담 {#명확한-역할-분담}

-   각 에이전트는 하나의 명확한 책임을 가짐
-   역할 간 중복 최소화
-   전문성 극대화


#### 모델 전략적 배치 {#모델-전략적-배치}

-   Haiku (2개): 빠른 응답이 필요한 작업 (git, tester)
-   Sonnet (10개): 표준 작업, 품질 중시


#### Temperature 최적화 {#temperature-최적화}

-   0.1: 정확성 최우선 (5개)
-   0.2: 체계적 일관성 (2개)
-   0.3: 구조적 창의성 (1개)
-   0.4: 자연스러운 문서 (1개)
-   0.6: 탐색적 조사 (1개)
-   0.7: 창의적 설계 (1개)
-   0.8: 자연스러운 표현 (1개)


### 전체 에이전트 목록 (12개) {#전체-에이전트-목록--12개}


#### 기본 개발 워크플로우 (6개) {#기본-개발-워크플로우--6개}


##### reviewer (sonnet, 0.1) {#reviewer--sonnet-0-dot-1}

-   역할: 코드 품질/보안 리뷰
-   도구: Read, Grep, Glob (읽기 전용)
-   특징: 정확한 분석, 보안 취약점 탐지
-   사용 시점: 코드 작성 후 품질 검토


##### refactor (sonnet, 0.3) {#refactor--sonnet-0-dot-3}

-   역할: 코드 리팩토링
-   도구: Read, Write, Edit, Grep, Glob, Bash
-   특징: 구조 개선, 성능 최적화
-   사용 시점: 코드베이스 개선


##### debugger (sonnet, 0.2) {#debugger--sonnet-0-dot-2}

-   역할: 버그 추적 및 디버깅
-   도구: Read, Grep, Glob, Bash
-   특징: 체계적 근본 원인 분석
-   사용 시점: 에러 조사, 버그 해결


##### architect (sonnet, 0.7) {#architect--sonnet-0-dot-7}

-   역할: 시스템 아키텍처 설계
-   도구: Read, Write, Grep, Glob + WebSearch, Context7
-   특징: 창의적 시스템 설계, 기술 의사결정
-   사용 시점: 시스템 설계, 기술 스택 선택


##### researcher (sonnet, 0.6) {#researcher--sonnet-0-dot-6}

-   역할: 기술 조사 및 라이브러리 비교
-   도구: Read, Grep + WebSearch, WebFetch, Context7
-   특징: 탐색적 조사, 베스트 프랙티스 발견
-   사용 시점: 기술 선택, 솔루션 탐색


##### tester (haiku, 0.1) {#tester--haiku-0-dot-1}

-   역할: 시스템 테스트, 로그 분석
-   도구: Read, Write, Bash, Grep, Glob
-   특징: 빠른 로그 분석, 원격 시스템 관리
-   사용 시점: 테스트 실행, 모니터링


#### 문서화 워크플로우 (2개) {#문서화-워크플로우--2개}


##### docs (sonnet, 0.4) {#docs--sonnet-0-dot-4}

-   역할: 기술 문서 작성
-   도구: Read, Write, Edit, Grep, Glob
-   특징: 명확하고 간결한 문서
-   사용 시점: README, API 문서, 가이드 작성


##### translator (sonnet, 0.8) {#translator--sonnet-0-dot-8}

-   역할: 한영 번역 및 현지화
-   도구: Read, Write, Edit
-   특징: 자연스러운 표현, 문화적 맥락 고려
-   사용 시점: 문서 번역, 블로그 현지화


#### 관리 워크플로우 (4개) {#관리-워크플로우--4개}


##### pm (sonnet, 0.2) {#pm--sonnet-0-dot-2}

-   역할: 프로젝트 관리, 메모리 관리
-   도구: Read, Write, Grep, Glob, Bash
-   특징: 능동적 메모리 스캔, 문서 정리
-   사용 시점: 프로젝트 상태 점검, 문서 통합


##### org (sonnet, 0.1) {#org--sonnet-0-dot-1}

-   역할: Org-mode PKM 관리
-   도구: Read, Write, Edit, Grep, Glob, Bash
-   특징: 구조적 파싱, Denote 표준 준수
-   사용 시점: Org-mode 파일 작업, 지식 관리


##### git (haiku, 0.1) {#git--haiku-0-dot-1}

-   특징: 전문적인 커밋 메시지, 빠른 처리
-   사용 시점: 변경사항 커밋


##### security (sonnet, 0.1) {#security--sonnet-0-dot-1}

-   역할: 보안 포렌식 분석
-   도구: Read, Write, Grep, Glob, Bash
-   특징: 취약점 분석, 로그 포렌식
-   사용 시점: 보안 감사, 사고 조사

##### 위치 {#위치}

```text
~/claude-config/opencode/agent/
```


##### 양식 {#양식}

```yaml
---
description: 설명
mode: subagent
model: anthropic/claude-[model]-4-5
temperature: 0.1-0.8
tools:
  read: true/false
  write: true/false
  edit: true/false
  grep: true/false
  glob: true/false
  bash: true/false
  list: true/false
---
```


##### 특징 {#특징}

-   mode: subagent 필수
-   명시적인 모델 경로 (anthropic/claude-\*)
-   도구별 boolean 객체 구조

#### Oh-My-OpenCode {#oh-my-opencode}

**개요**

-   OpenCode를 위한 올인원 플러그인
-   Sisyphus 에이전트를 중심으로 다중 AI 모델 오케스트레이션
-   "The Best Agent Harness"를 표방

**핵심 특징**

-   **다중 모델 활용**: Claude Opus 4.5, GPT 5.2 Medium, Gemini 3 Pro 등 특화된 모델들을 동시 활용
-   **전문 에이전트**:
    -   Sisyphus (Claude Opus 4.5): 메인 오케스트레이터
    -   Oracle (GPT 5.2): 아키텍처 및 디버깅
    -   Frontend Engineer (Gemini 3 Pro): UI/UX 개발
    -   Librarian (Claude Sonnet 4.5): 문서화 및 코드 탐색
    -   Explore: 빠른 코드베이스 검색

**기술 스택**

-   LSP(Language Server Protocol) 완벽 지원
-   AST-Grep 통합(구문 인식 코드 검색)
-   MCP(Model Context Protocol) 내장: Exa(웹 검색), Context7(문서), GitHub 검색
-   Todo Continuation Enforcer(작업 미완성 방지)

**장점**

-   8,000+ ESLint 경고를 하루 만에 처리
-   45,000줄 애플리케이션을 하룻밤 사이에 변환
-   병렬 백그라운드 에이전트로 컨텍스트 부하 감소
-   "ultrawork" 키워드로 전체 기능 자동 활성화

**이슈**

-   2026년 1월 현재 Anthropic의 제3자 OAuth 접근 제한으로 차단 문제 발생


#### GAS-TOWN {#gas-town}

**개요**

-   Claude Code를 위한 다중 에이전트 오케스트레이터
-   Git 기반 작업 상태 관리(Beads)
-   Tmux 세션 기반 에이전트 실행

**핵심 특징**
