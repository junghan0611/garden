#### @user how to use mouse in org-mode on emacs? {#user-how-to-use-mouse-in-org-mode-on-emacs}

@assistant Org-mode에서 마우스 사용 방법:

1.  기본 동작:
2.  헤드라인 클릭: 접기/펼치기
3.  링크 더블클릭: 링크 열기
4.  체크박스 클릭: 상태 변경

5.  유용한 설정 (init.el에 추가):

<!--listend-->

```elisp
;; 마우스로 헤드라인 드래그 시 재정렬 허용
(setq org-support-shift-select t)
```

1.  확장 기능:
2.  `org-mouse` 패키지 설치하면 추가 기능 사용 가능
3.  표 편집 시 마우스로 셀 선택 가능

주의: Emacs는 주로 키보드 중심으로 설계되어 마우스 지원이 제한적일 수 있습니다.
