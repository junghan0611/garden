## 한 줄 {#한-줄}

> Magit을 다 쓸 필요도, 다 맡길 필요도 없다. 사람은 상태와 검색의 핵심만, 에이전트는 ghcli 면 — 그 중간쯤이 닷파일이다.


## 해설 — 손의 분담 {#해설-손의-분담}

doomemacs-config 주석에 이미 박혀 있는 분할:

| 표면            | 누가     | 무엇을                               |
|---------------|--------|-----------------------------------|
| **Magit**       | 인간 (상시) | 로컬 상태, 스테이징, 커밋 리듬, 브랜치. 여태 씀. |
| **gptel-magit** | 인간+모델 | 커밋 메시지 보조. 커밋 권한·훅은 그대로 인간/정책. |
| **magit-gh**    | 인간     | **현재 Magit 리포** 안의 PR 면       |
| **consult-gh**  | 인간     | 전역 repo/code/issue 검색. 브라우저 대신. 핵심만. |
| **ghcli**       | 에이전트 | 이슈 _PR_ 알림 등 CLI 작업면         |
| **forge 풀세트** | 기본 제외 경향 | 예전에 무거웠던 층 — 필요 시 이웃 노트 |

consult-gh 재도입 원칙(원석·설정 일치):

-   예전에 기능이 많아 지저분해서 닷파일에서 뺐다.
-   버전 업을 보고 안정화 감각이 와서 **간단하게** 다시 넣음.
-   모든 기능 금지에 가깝게: 검색 + 계정 전환 중심. embark/forge/pr-review/omni/ 대시보드 키 안 깔기.
-   클론 기본 디렉터리 `~/repos/3rd/`, 프리뷰는 이맥스 안, 브라우저는 피하려는 대상.

에이전트에게 Magit UI를 통째로 맡기지 않는다. 에이전트는 ghcli·커밋 스킬 계약 위에서 일하고, 인간은 상태 버퍼와 검색 표면을 쥔다. GUI 전용 플러그인으로 툴을 불리지 않는 감각([조테로 BBT 유물]({{< relref "/notes/20230816T070200.md" >}})과 같은 방향)이 여기에도 있다.


## 해설 — 키 감각 (Doom) {#해설-키-감각--doom}

-   Magit 상태: 리더 `g` 계열 (Doom 기본)
-   consult-gh: 리더 `g h` 접두
    -   `g h s` 리포 검색
    -   `g h c` 코드 검색
    -   `g h i` 이슈 검색
    -   `g h a` 계정 전환
    -   `g h h` transient 메뉴 (래퍼로 올바른 feature require)

설정 세부는 리포가 SSOT. 이 방은 **왜 이렇게 나눴는가** 만 고정한다.


## 오독 주의 {#오독-주의}

-   Spacemacs `SPC g …` 표 전체를 이 방의 본문으로 부활시키지 않는다. 옛 덤프는 접었다.
-   consult-gh를 에이전트 기본 GitHub 도구로 읽지 않는다. 에이전트는 ghcli.
-   gptel-magit을 자동 커밋·훅 우회로 읽지 않는다.
