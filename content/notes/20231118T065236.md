## DONT install 'homebrew' and 'scrcpy' {#dont-install-homebrew-and-scrcpy}

-   <span class="timestamp-wrapper"><span class="timestamp">[2024-04-28 Sun 06:19]</span></span> homebrew 안쓴다. 공간 많이 차지. 하지마라
-   <span class="timestamp-wrapper"><span class="timestamp">[2023-11-18 Sat 05:59]</span></span> 리눅스에서도 가능하다. 설치하면 된다. 왜? 홈브루가 필요한가? 패키지를 최신 버전으로 제공하니까.

<!--listend-->

<a id="code-snippet--install homebrew"></a>
```bash

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

test -d ~/.linuxbrew && eval "$(~/.linuxbrew/bin/brew shellenv)"
test -d /home/linuxbrew/.linuxbrew && eval "$(/home/linuxbrew/.linuxbrew/bin/brew shellenv)"
echo "eval \"\$($(brew --prefix)/bin/brew shellenv)\"" >> ~/.bashrc

brew install scrcpy
sudo apt-get install adb

```
