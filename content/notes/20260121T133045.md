## Threads API 토큰 갱신 및 memex-kb Flake 전환 {#threads-api-토큰-갱신-및-memex-kb-flake-전환}

<span class="timestamp-wrapper"><span class="timestamp">[2026-01-21 Wed 22:27]</span></span>


### 배경 {#배경}

memex-kb 프로젝트의 Threads API 토큰이 만료되어 갱신 작업 진행. 기존 방법(User Token Generator)이 작동하지 않아 새로운 방법 발견.


### 핵심 발견: Graph API Explorer + threads.net API {#핵심-발견-graph-api-explorer-plus-threads-dot-net-api}


#### 토큰 발급 방법 (2026-01-21 검증) {#토큰-발급-방법--2026-01-21-검증}

1.  Graph API Explorer 접속
    -   <https://developers.facebook.com/tools/explorer/1351795096326806/>

2.  **중요**: 상단 드롭다운에서 API를 `threads.net` 으로 변경
    -   기본값은 `graph.facebook.com` 이라 작동 안 함

3.  "Generate Access Token" 클릭 → 단기 토큰 획득

4.  장기 토큰(60일)으로 교환:
    ```bash
       nix develop --command python scripts/refresh_threads_token.py --exchange "단기토큰"
    ```


#### 왜 User Token Generator는 안 됐나 {#왜-user-token-generator는-안-됐나}

-   테스터 계정 매칭 문제
-   "Invalid Auth Code: Credentials entered do not match the selected tester profile"
-   Meta의 복잡한 계정 체계 (Facebook/Instagram/Threads)


### memex-kb 개선 작업 {#memex-kb-개선-작업}


#### 1. Nix Flake 전환 {#1-dot-nix-flake-전환}

`shell.nix` → `flake.nix` 전환으로 빌드 속도 개선.

```bash
# 이전 (느림 - 매번 nixpkgs 평가)
nix-shell --run "python scripts/..."

# 이후 (빠름 - 캐싱)
nix develop --command python scripts/...
```


#### 2. 토큰 갱신 스크립트 생성 {#2-dot-토큰-갱신-스크립트-생성}

`scripts/refresh_threads_token.py` 생성:

```bash
# 단기 → 장기 토큰 교환 (가장 많이 사용)
python refresh_threads_token.py --exchange "THAA..."

# 현재 토큰 테스트
python refresh_threads_token.py --test

# 기존 장기 토큰 갱신 (만료 전)
python refresh_threads_token.py
```


#### 3. secretlint → gitleaks 교체 {#3-dot-secretlint-gitleaks-교체}

npm 의존성 제거, Nix로 통합.

```bash
# git repo 스캔
gitleaks detect

# 일반 파일 스캔 (디지털 가든 배포 전 검사용)
gitleaks detect --source=/path/to/files --no-git
```


#### 4. direnv 연동 {#4-dot-direnv-연동}

`.envrc` 추가로 디렉토리 진입 시 자동 환경 로드.


### 삭제된 파일 {#삭제된-파일}

-   `shell.nix` → `flake.nix` 로 대체
-   `requirements.txt` → `flake.nix` 에서 Python 패키지 관리
-   `package.json`, `package-lock.json` → `gitleaks` 로 대체
