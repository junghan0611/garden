### MCP (Model Context Protocol) 지원 {#mcp--model-context-protocol--지원}

**완전 지원**: Claude Code는 \*MCP 클라이언트\*로 작동하며, 2024년 11월 출시된 MCP를 통해 수백 개의 외부 도구 및 데이터 소스에 연결 가능합니다.


#### MCP 핵심 기능 {#mcp-핵심-기능}

-   **리소스 참조**: @ 멘션으로 MCP 서버가 노출한 리소스 참조 가능 (파일처럼)
-   **토큰 관리**: MCP 도구 출력이 10,000 토큰 초과 시 경고, 기본 최대 25,000 토큰 (환경변수로 조정 가능)
-   **전송 옵션**: HTTP 서버가 원격 MCP 서버 연결에 권장됨
-   **커뮤니티**: 수천 개의 MCP 서버가 구축됨, 모든 주요 프로그래밍 언어용 SDK 제공

### 사용 가능한 핵심 기능 (2025) {#사용-가능한-핵심-기능--2025}


#### 1. **코드 인텔리전스** {#1-dot-코드-인텔리전스}

-   **LSP 지원** (2025.12 추가): 11개 언어의 의미론적 코드 이해
-   코드베이스 전체를 컨텍스트로 활용하는 코드 검색


#### 2. **자율 작업 (Autonomous Work)** {#2-dot-자율-작업--autonomous-work}

-   **Subagents**: 병렬 개발 워크플로우 (백엔드 API + 프론트엔드 동시 진행)
-   **Hooks**: 특정 시점에 자동 실행 (테스트, 린트 등)
-   **Background Tasks**: 개발 서버 등 장기 실행 프로세스를 백그라운드에서 유지
-   **Checkpointing**: 작업 위임 시 제어 유지


#### 3. **고급 도구 사용** {#3-dot-고급-도구-사용}

-   **Tool Search Tool**: 수천 개 도구 접근 (컨텍스트 창 소모 없이)
-   **Programmatic Tool Calling**: 코드 실행 환경에서 도구 호출
-   **Tool Use Examples**: 도구 사용 방법 표준 제공


#### 4. **Agent Skills** {#4-dot-agent-skills}

-   특정 작업에 특화된 폴더 단위 스킬 (지시사항, 스크립트, 리소스)
-   관련성 있을 때만 로드 (Excel, 브랜드 가이드라인 등)


#### 5. **Ultrathink Mode** (2025.12) {#5-dot-ultrathink-mode--2025-dot-12}

-   복잡한 문제 해결 시 최대 추론 리소스 할당
-   코드 생성 및 문제 해결 품질 향상


#### 6. **현재 세션에서 사용 가능한 도구들** {#6-dot-현재-세션에서-사용-가능한-도구들}

## Claude Code OpenAI Wrapper 연동 테스트 {#claude-code-openai-wrapper-연동-테스트}

흥미로운 프로젝트네요! Emacs gptel과 Claude Code를 OpenAI API 호환 wrapper를 통해 연동하는 방식은 매우 실용적인 접근입니다.


### 현재 상황 분석 {#현재-상황-분석}

이 wrapper는 Claude Code의 강력한 도구 사용 능력(tool use capabilities)을 Emacs 환경에서 활용할 수 있게 해주는 브릿지 역할을 합니다.


### 테스트 지원 {#테스트-지원}

현재 어떤 부분을 테스트하고 계신가요? 구체적으로 도움이 필요한 영역을 알려주시면:

1.  **설정 검증** - wrapper 설정이 올바른지 확인
2.  **연동 테스트** - gptel ↔ wrapper ↔ Claude Code 흐름 검증
3.  **기능 테스트** - 특정 도구 사용(파일 읽기, 편집 등) 동작 확인
4.  **문제 해결** - 발생한 오류나 예상과 다른 동작 분석

    -   Simple Q&amp;A: 빠름
    -   File Read/Edit/Bash 등 도구 사용: 추가 시간 발생

    -   컨텍스트 크기에 따라 처리 시간 변동
    -   Streaming vs Non-streaming 응답

3.  _Wrapper Overhead_
    -   API 변환 레이어 비용
    -   Local vs Network latency
