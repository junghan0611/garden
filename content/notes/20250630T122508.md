## 키워드 정리 {#키워드-정리}


### IoT 플랫폼 관련 영한 키워드 목록 {#iot-플랫폼-관련-영한-키워드-목록}


#### **1. 기본 개념** {#1-dot-기본-개념}

-   **IoT Platform (아이오티 플랫폼)**
-   **Device Management (장치 관리)**
-   **Data Collection (데이터 수집)**
-   **Data Processing (데이터 처리)**
-   **Data Visualization (데이터 시각화)**
-   **Telemetry (원격 측정)**
-   **Real-time Monitoring (실시간 모니터링)**
-   **Edge Computing (엣지 컴퓨팅)**


#### **2. 기술 및 프로토콜** {#2-dot-기술-및-프로토콜}

-   **MQTT (Message Queuing Telemetry Transport)**
-   **CoAP (Constrained Application Protocol)**
-   **HTTP (Hypertext Transfer Protocol)**
-   **WebSocket (웹소켓)**
-   **LwM2M (Lightweight M2M, 경량 M2M 프로토콜)**
-   **REST API (RESTful API)**
-   **RPC (Remote Procedure Call, 원격 프로시저 호출)**


#### **3. 아키텍처 및 배포** {#3-dot-아키텍처-및-배포}

-   **Cloud Deployment (클라우드 배포)**
-   **On-Premises Deployment (온프레미스 배포)**
-   **Microservices Architecture (마이크로서비스 아키텍처)**
-   **Scalability (확장성)**
-   **Fault Tolerance (내결함성)**
-   **Horizontal Scaling (수평 확장)**


#### **4. 주요 기능** {#4-dot-주요-기능}

-   **Rule Engine (규칙 엔진)**
-   **Dashboard (대시보드)**
-   **Alarm Triggering (알람 트리거링)**
-   **Workflow Automation (워크플로우 자동화)**
-   **SCADA Integration (SCADA 통합)**
-   **Custom Widgets (사용자 정의 위젯)**


#### **5. 주요 오픈소스 플랫폼** {#5-dot-주요-오픈소스-플랫폼}

-   **ThingsBoard (띵스보드)**
-   **Kaa IoT Platform (카아 IoT 플랫폼)**
-   **OpenRemote (오픈리모트)**
-   **Mainflux (메인플럭스)**
-   **Eclipse IoT (이클립스 IoT)**

이 키워드들은 IoT 플랫폼의 핵심 개념, 기술 스택, 아키텍처, 주요 기능 및 대표적인 솔루션을 포괄합니다.


### ThingsBoard와 유사한 오픈소스 IoT 플랫폼 {#thingsboard와-유사한-오픈소스-iot-플랫폼}

| 플랫폼명             | 주요 특징                                 | 프로토콜 지원         | 배포 형태  |
|------------------|---------------------------------------|-----------------|--------|
| **ThingsBoard**      | 장치 관리, 데이터 수집/처리/시각화, 규칙 엔진, 마이크로서비스 아키텍처 | MQTT, CoAP, HTTP      | 클라우드/온프레미스 |
| **Kaa IoT Platform** | 유연한 장치 관리, 데이터 수집, 분석, 확장성 높은 아키텍처 | MQTT, CoAP, HTTP 등   | 클라우드/온프레미스 |
| **OpenRemote**       | IoT 및 스마트 빌딩 자동화에 특화, 사용자 정의 가능한 대시보드 | MQTT, HTTP 등         | 클라우드/온프레미스 |
| **Mainflux**         | 클라우드 네이티브 IoT 플랫폼, 마이크로서비스 기반, 보안 강화 | MQTT, HTTP, WebSocket | 클라우드/온프레미스 |
| **Eclipse IoT**      | 다양한 오픈소스 IoT 프로젝트 모음, 프로토콜 및 도구 지원 다양 | MQTT, CoAP, LwM2M 등  | 클라우드/온프레미스 |

이들 플랫폼은 모두 IoT 장치 관리, 데이터 수집 및 시각화, 원격 제어 기능을 제공하며, 산업 표준 프로토콜을 지원해 다양한 IoT 프로젝트에 활용할 수 있습니다. 특히 ThingsBoard는 풍부한 위젯과 규칙 엔진, SCADA 지원 등으로 실시간 모니터링과 복잡한 워크플로우 관리에 강점을 보입니다[1][2].

---

요약하면, ThingsBoard는 확장성, 내결함성, 다양한 프로토콜 지원과 풍부한 기능을 갖춘 오픈소스 IoT 플랫폼으로, 유사한 목적의 다른 오픈소스 프로젝트들과 함께 IoT 솔루션 개발에 널리 사용되고 있습니다.
