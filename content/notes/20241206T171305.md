## @assistant  Hugo 블로그 엔진에서 CJK(중국어, 일본어, 한국어)로 작성된 단어가 연결되도록 설정하는 방법은 다음과 같습니다: {#assistant-hugo-블로그-엔진에서-cjk--중국어-일본어-한국어--로-작성된-단어가-연결되도록-설정하는-방법은-다음과-같습니다}

1.  **Language 설정**: `config.toml` 또는 `config.yaml` 파일에서 언어 설정을 CJK 언어로 지정합니다. 예를 들어, 한국어를 사용하려면:
    ```toml
       [languages.ko]
       languagedirection = "ltr"
       title = "내 블로그"
       weight = 1
    ```

2.  **Markdown Renderer 설정**: Hugo는 기본적으로 =Blackfriday=를 사용하지만, CJK 언어 지원을 위해 =Goldmark=로 변경하는 것이 좋습니다. =config.toml=에 다음과 같이 설정합니다:
    ```toml
       [markup]
         [markup.goldmark]
           [markup.goldmark.renderer]
             unsafe = true
    ```

3.  **CJK Line Breaks**: Markdown에서 CJK 문자 사이의 줄바꿈을 처리하는 방법을 설정할 수 있습니다. =config.toml=에 다음과 같이 추가합니다:
    ```toml
       [markup.goldmark.parser]
         autoHeadingID = true
         autoHeadingIDType = "github"
         [markup.goldmark.parser.attribute]
           block = false
           title = true
         [markup.goldmark.renderer.hardWraps]
           lineBreak = "soft"
    ```
    여기서 =lineBreak = "soft"=는 CJK 문자 사이의 줄바꿈을 부드럽게 처리하도록 설정합니다.

4.  **CSS 조정**: CJK 문자 사이의 간격을 조정하기 위해 CSS를 사용할 수 있습니다. 예를 들어, `static/css/custom.css` 파일에 다음과 같은 스타일을 추가할 수 있습니다:
    ```css
       body {
         word-break: break-all;
         word-wrap: break-word;
       }
    ```
    이는 긴 단어가 화면 너비를 초과할 때 자동으로 줄바꿈되도록 합니다.

5.  **Hugo Theme**: 사용하는 테마가 CJK 언어를 지원하는지 확인하고, 필요하다면 테마의 설정 파일을 수정하거나 CJK 언어에 맞게 커스터마이징합니다.

위의 설정들을 적용하면 CJK 언어로 작성된 단어가 Hugo 블로그에서 자연스럽게 연결되어 표시될 것입니다. 필요에 따라 추가적인 조정이 필요할 수 있으니, Hugo의 공식 문서나 커뮤니티에서 더 많은 정보를 얻을 수 있습니다.
