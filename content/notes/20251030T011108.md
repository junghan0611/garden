## claude-config: AI Agent 협업 지휘소 {#claude-config-ai-agent-협업-지휘소}


### 프로젝트 목표 {#프로젝트-목표}

Claude AI 어시스턴트와의 효과적인 협업을 위한 ****홈 디렉토리 관리 시스템****.


### 핵심 파일 {#핵심-파일}

-   ****CLAUDE.md****: Agent 실행 지침서 (버전 3.2.0)
-   ****CLAUDE-ANALYSIS.md****: 설계 철학 및 변화 설명


### 구조 {#구조}

```text
claude-config/
├── CLAUDE.md           # Agent 지침서
├── CLAUDE-ANALYSIS.md  # 설계 철학
└── README.md
```


### 심볼릭 링크 {#심볼릭-링크}

```bash
~/CLAUDE.md → ~/sync/.../claude-config/CLAUDE.md
~/CLAUDE-ANALYSIS.md → ~/sync/.../claude-config/CLAUDE-ANALYSIS.md
```


### 철학적 기반 {#철학적-기반}


#### Before: 사용자 매뉴얼 {#before-사용자-매뉴얼}

-   사람이 읽고 이해하기 위한 문서
-   수동적 도구 사용 가이드


#### After: AGENT 지침서 {#after-agent-지침서}

-   AGENT가 자동 실행할 지침
-   능동적 지능형 어시스턴트
-   역할과 자동 행동 중심


### 메모리 시스템 (PARA) {#메모리-시스템--para}

```text
~/claude-memory/
├── projects/        # 기한 있는 활성 프로젝트
├── areas/           # 지속적 관심사
├── resources/       # 재사용 자원
│   ├── solutions/   # 문제 해결 패턴
│   ├── snippets/    # 코드 조각
│   └── workflows/   # 작업 프로세스
└── archives/        # 완료/비활성
```


### 자동 수행 기능 {#자동-수행-기능}

1.  컨텍스트 파악 및 로드
2.  메모리 검색 및 저장
3.  워크플로우 캡처
4.  프로젝트 상태 추적
5.  추론 능력 자동 활성화


### Denote 파일명 규칙 {#denote-파일명-규칙}

```text
timestamp--한글-제목__영어_태그들.org
예시: 20250907T135000--ai-대화-세션__laptop.org
```


### 태그 시스템 {#태그-시스템}

```text
__active     # 현재 진행 중
__urgent     # 긴급
__blocked    # 차단됨
__solution   # 해결 패턴
__done       # 완료됨
```
