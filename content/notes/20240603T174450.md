### 목표 - 실행 자동완성 {#목표-실행-자동완성}

다음을 실행하는 것

```python
print("hello")
x = 'foo'
y = 'bar'
x + ' ' + y
```

```text
hello
foo bar
```

jupyter-run-repl 이건 둠이맥스가 좋다

설치 하고 레플 열고

```python
print("hello")
```

```text
hello
```
