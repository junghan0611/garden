## <span class="org-todo todo TODO">TODO</span> Ubuntu Google Drive 동기화 솔루션 검토 {#ubuntu-google-drive-동기화-솔루션-검토}

<span class="timestamp-wrapper"><span class="timestamp">[2025-10-01 Wed 10:26]</span></span>

```markdown

1. Rclone (무료, 강력함)
# 설치
sudo apt install rclone

# 설정
rclone config  # Google Drive 연동 설정
rclone mount gdrive: ~/gdrive  # 마운트
rclone bisync gdrive: ~/local-folder  # 양방향 동기화

2. Insync (유료, 쉬움)
- 일회성 결제 ($39.99)
- GUI 제공, 가장 완성도 높음
# 저장소 추가 후 설치
sudo apt-key adv --keyserver keyserver.ubuntu.com --recv-keys ACCAF35C
sudo apt install insync

3. Celeste (무료 GUI)
- Rclone 백엔드 + GUI
sudo snap install celeste
# 또는
flatpak install flathub com.hunterwittenborn.Celeste

🎯 추천

회사용: Rclone + systemd 자동화
- 무료, 스크립트 연동 가능
- cron/systemd로 자동 동기화

```
