### 📌 문제 정의 {#문제-정의}


#### 현실: 8시간 리팩터링의 실패 {#현실-8시간-리팩터링의-실패}

**배경**:

-   프로젝트: sks-gateway (11,000 라인 C 코드)
-   소요: 매일 8시간 풀타임 (3주)
-   성과: 전임자 코드 분석, 문서화, 주요 기능 검증
-   **문제**: 8시간 리팩터링 후 결국 수동 작업 → 아침 코드로 롤백


#### 에이전트의 비효율적 패턴 {#에이전트의-비효율적-패턴}

```text
1. grep으로 함수 찾기
   → 파일 편집하면 라인번호 변경
   → 오탐지 많음 (주석, 문자열도 매칭)
   → 함수 시작/끝을 매번 재계산

2. ctags 정보 사용 불가
   → 빌드가 필요함
   → 서버 환경에서 불가능
   → 편집 후 재생성 필요

3. Emacs ↔ 에이전트 정보 단절
   → treesit/eglot/clangd가 실시간 정보 보유
   → 하지만 에이전트에게 전달 안 됨
   → revert-buffer 기다릴 수 없음

4. 파이썬 스크립트 남발
   → 코드 분석/편집마다 새 스크립트
   → 재사용 불가
   → 시간 낭비
```


#### 핵심 요구사항 {#핵심-요구사항}

> **항상 최신 정보로 찾고, 함수 지우고, 편집할 수 있어야 한다.** **revert-buffer를 못 기다린다.** **매번 라이브 정보로 바로 확인해야 한다.**

#### 핵심 통찰 {#핵심-통찰}

> **grep의 문제**:
> 
> -   텍스트 기반 → 구조 모름 → 편집 시 outdated
> 
> **AST의 장점**:
> 
> -   구조 기반 → 정확함 → 항상 최신

| 비교  | grep (기존)   | AST (새로운) |
|-----|-------------|-----------|
| 검색 방식 | 텍스트 매칭   | 구조 매칭 |
| 정확도 | 낮음 (오탐지) | 100%      |
| 최신성 | 편집 후 outdated | 항상 최신 |
| 속도  | 2-3초         | &lt;1초   |
| 구분  | 선언/정의 혼재 | 정확히 구분 |

#### 도구 4: code-query.sh (실험적, 개선 필요) {#도구-4-code-query-dot-sh--실험적-개선-필요}

**목적**: clang-query 기반 AST 검색

**현재 상태**: ⚠️ Match #1 표시되지만 상세 정보 없음

**임시 결론**: index-code.py로 충분함 (더 빠르고 실용적)

```bash
#!/bin/bash
# code-query.sh - Real-time C code query using clang-query
# Purpose: Agent-friendly interface without grep

set -euo pipefail

# Colors
RED='\033[0;31m'
GREEN='\033[0;32m'
YELLOW='\033[1;33m'
BLUE='\033[0;34m'
NC='\033[0m'

COMPILE_DB="${1:-./compile_commands.json}"
QUERY_TYPE="${2:-}"
QUERY_PARAM="${3:-}"

if [ ! -f "$COMPILE_DB" ]; then
    echo -e "${RED}✗ compile_commands.json not found${NC}"
    echo "  Run: ./tools/cmake/setup_compile_db.sh first"
    exit 1
fi

if ! command -v clang-query &> /dev/null; then
    echo -e "${RED}✗ clang-query not found${NC}"
    echo "  Install: nix-shell or apt install clang-tools"
    exit 1
fi

print_usage() {
    cat << EOF
${BLUE}code-query.sh - C Code Search Tool${NC}

Usage: code-query.sh [COMPILE_DB] [QUERY_TYPE] [PATTERN]

Query Types:
  ${YELLOW}functions${NC}         - Find function declarations
  ${YELLOW}function${NC}          - Find specific function
  ${YELLOW}structs${NC}           - Find struct/union declarations
  ${YELLOW}struct${NC}            - Find specific struct
  ${YELLOW}macros${NC}            - Find macro definitions
  ${YELLOW}calls${NC}             - Find function calls to pattern
  ${YELLOW}refs${NC}              - Find symbol references

Examples:
  code-query.sh compile_commands.json functions
  code-query.sh compile_commands.json function mqtt_pub
  code-query.sh compile_commands.json struct Device
  code-query.sh compile_commands.json calls mqtt
  code-query.sh compile_commands.json refs shadow_update
EOF
}

# Query builders
query_all_functions() {
    echo "match functionDecl()"
}

query_function() {
    local name="$1"
    echo "match functionDecl(hasName(\"$name\"))"
}

query_all_structs() {
    echo "match cxxRecordDecl()"
}

query_struct() {
    local name="$1"
    echo "match cxxRecordDecl(hasName(\"$name\"))"
}

query_function_calls() {
    local pattern="$1"
    echo "match callExpr(callee(functionDecl(hasName(\".*$pattern.*\"))))"
}

query_symbol_refs() {
    local pattern="$1"
    echo "match declRefExpr(to(namedDecl(hasName(\".*$pattern.*\"))))"
}

# Execute query
execute_query() {
    local query="$1"
    clang-query "$COMPILE_DB" << EOF
set output diag
$query
EOF
}

# Main dispatch
case "${QUERY_TYPE:-help}" in
    help|"")
        print_usage
        ;;
    functions)
        echo -e "${GREEN}Finding all function declarations...${NC}"
        execute_query "$(query_all_functions)" | grep "FunctionDecl" || echo "No functions found"
        ;;
    function)
        [ -z "$QUERY_PARAM" ] && echo -e "${RED}Error: function name required${NC}" && exit 1
        echo -e "${GREEN}Finding function: $QUERY_PARAM${NC}"
        execute_query "$(query_function "$QUERY_PARAM")"
        ;;
    structs)
        echo -e "${GREEN}Finding all struct/union declarations...${NC}"
        execute_query "$(query_all_structs)" | grep -E "RecordDecl|Union" || echo "No structs found"
        ;;
    struct)
        [ -z "$QUERY_PARAM" ] && echo -e "${RED}Error: struct name required${NC}" && exit 1
        echo -e "${GREEN}Finding struct: $QUERY_PARAM${NC}"
        execute_query "$(query_struct "$QUERY_PARAM")"
        ;;
    calls)
        [ -z "$QUERY_PARAM" ] && echo -e "${RED}Error: function pattern required${NC}" && exit 1
        echo -e "${GREEN}Finding calls to: $QUERY_PARAM${NC}"
        execute_query "$(query_function_calls "$QUERY_PARAM")"
        ;;
    refs)
        [ -z "$QUERY_PARAM" ] && echo -e "${RED}Error: symbol pattern required${NC}" && exit 1
        echo -e "${GREEN}Finding references to: $QUERY_PARAM${NC}"
        execute_query "$(query_symbol_refs "$QUERY_PARAM")"
        ;;
    *)
        echo -e "${RED}Unknown query type: $QUERY_TYPE${NC}"
        print_usage
        exit 1
        ;;
esac
```

**사용 예제**:

#### 도구 3: index-code.py {#도구-3-index-code-dot-py}

**목적**: 11,000 라인 코드의 조감도 생성

```python
#!/usr/bin/env python3
"""
index-code.py - Real-time C code indexing for agent navigation
Generates queryable index of functions, structs, macros, includes
"""

import json
import sys
import re
from pathlib import Path
from typing import List, Dict, Any
import argparse

class CCodeIndexer:
    def __init__(self, src_dir: str = "src"):
        self.src_dir = Path(src_dir)
        self.index = {
            "functions": [],
            "structs": [],
            "macros": [],
            "typedefs": [],
            "includes": [],
            "globals": [],
            "metadata": {"total_lines": 0, "total_files": 0}
        }

    def index_files(self) -> Dict[str, Any]:
        """Index all C/H files in src directory"""
        c_files = list(self.src_dir.glob("**/*.c")) + list(self.src_dir.glob("**/*.h"))
        print(f"Indexing {len(c_files)} files in {self.src_dir}...")

        total_lines = 0
        for filepath in sorted(c_files):
            total_lines += self._index_file(filepath)

        self.index["metadata"]["total_lines"] = total_lines
        self.index["metadata"]["total_files"] = len(c_files)
        return self.index

    def _index_file(self, filepath: Path) -> int:
        """Index a single C/H file"""
        try:
            with open(filepath, 'r', encoding='utf-8', errors='ignore') as f:
                lines = f.read().split('\n')

            relative_path = filepath.relative_to(Path.cwd())

            self._find_functions(str(relative_path), lines)
            self._find_structs(str(relative_path), lines)
            self._find_macros(str(relative_path), lines)

            return len(lines)
        except Exception as e:
            print(f"⚠ Error: {filepath}: {e}", file=sys.stderr)
            return 0

    def _find_functions(self, filepath: str, lines: List[str]):
        """Find function definitions"""
        for i, line in enumerate(lines, 1):
            if line.strip().startswith(('/*', '//', 'typedef', 'extern')):
                continue
            if re.search(r'\w+\s*\([^)]*\)\s*\{', line):
                match = re.search(r'(\w+)\s*\([^)]*\)\s*\{', line)
                if match:
                    func_name = match.group(1)
                    if func_name not in ('if', 'while', 'for', 'switch', 'return', 'struct', 'union'):
                        self.index["functions"].append({
                            "name": func_name,
                            "file": filepath,
                            "line": i,
                            "type": "definition"
                        })

    def _find_structs(self, filepath: str, lines: List[str]):
        """Find struct/union definitions"""
        for i, line in enumerate(lines, 1):
            match = re.search(r'^(struct|union)\s+(\w+)\s*\{', line)
            if match:
                self.index["structs"].append({
                    "name": match.group(2),
                    "type": match.group(1),
                    "file": filepath,
                    "line": i
                })

    def _find_macros(self, filepath: str, lines: List[str]):
        """Find #define macros"""
        for i, line in enumerate(lines, 1):
            match = re.search(r'^\s*#\s*define\s+(\w+)', line)
            if match:
                macro_name = match.group(1)
                value = line.split(macro_name, 1)[1].strip() if len(line.split(macro_name)) > 1 else ""
                self.index["macros"].append({
                    "name": macro_name,
                    "value": value[:80],
                    "file": filepath,
                    "line": i
                })

    def search(self, query: str, index_type: str = "all") -> List[Dict[str, Any]]:
        """Search in index"""
        results = []
        query_lower = query.lower()
        search_types = ["functions", "structs", "macros"] if index_type == "all" else [index_type]

        for type_name in search_types:
            for item in self.index.get(type_name, []):
                if query_lower in item.get("name", "").lower():
                    results.append({**item, "category": type_name})
        return results

    def export_json(self, filepath: str):
        """Export index to JSON"""
        with open(filepath, 'w') as f:
            json.dump(self.index, f, indent=2)
        print(f"✓ Index exported to {filepath}")

    def export_markdown(self, filepath: str):
        """Export index to Markdown"""
        with open(filepath, 'w') as f:
            f.write("# Code Index\n\n")
            f.write(f"**Total Files**: {self.index['metadata']['total_files']}\n")
            f.write(f"**Total Lines**: {self.index['metadata']['total_lines']}\n\n")

            f.write("## Functions\n\n")
            for item in self.index["functions"][:100]:
                f.write(f"- `{item['name']}` ({item['file']}:{item['line']})\n")
            f.write(f"\n*Total: {len(self.index['functions'])} functions*\n\n")

            f.write("## Structs\n\n")
            for item in self.index["structs"]:
                f.write(f"- `{item['name']}` ({item['type']}) ({item['file']}:{item['line']})\n")

        print(f"✓ Markdown exported to {filepath}")

def main():
    parser = argparse.ArgumentParser(description="C Code Indexer")
    parser.add_argument("--src", default="src", help="Source directory")
    parser.add_argument("--search", help="Search query")
    parser.add_argument("--type", default="all", help="Search type")
    parser.add_argument("--json", help="Export to JSON")
    parser.add_argument("--markdown", help="Export to Markdown")
    parser.add_argument("--export-all", action="store_true", help="Export both")
    args = parser.parse_args()

    indexer = CCodeIndexer(args.src)
    indexer.index_files()

    if args.search:
        results = indexer.search(args.search, args.type)
        print(f"\n🔍 Results for '{args.search}' ({len(results)}):\n")
        for r in results[:20]:
            print(f"  {r['category']:12} | {r['name']:30} | {r['file']}:{r['line']}")

    if args.json:
        indexer.export_json(args.json)
    if args.markdown:
        indexer.export_markdown(args.markdown)
    if args.export_all:
        indexer.export_json("code-index.json")
        indexer.export_markdown("code-index.md")

if __name__ == "__main__":
    main()
```

**출력**:

-   `code-index.json` (에이전트 파싱용)
-   `code-index.md` (사람 가독용)

### 🎓 크로스컴파일 교훈 (중요!) {#크로스컴파일-교훈--중요}


#### Host vs Target Architecture {#host-vs-target-architecture}

```text
컴파일러 명명 규칙: [HOST]-[TARGET]-gcc

x86_64-arm-linux-gnueabihf-gcc
  ↑        ↑
  호스트    타겟
  (실행됨)  (생성됨)
```

| 환경         | Host    | Target              | 컴파일러            | 비고       |
|------------|---------|---------------------|-----------------|----------|
| 노트북 (Ubuntu) | x86_64  | arm-linux-gnueabihf | SigmaStar GCC 9.1.0 | ✅ 권장    |
| 서버 (NixOS) | aarch64 | arm-linux-gnueabihf | pkgsCross armv7l    | ⚠️ ABI 불일치 |


#### bare-metal vs Linux Target {#bare-metal-vs-linux-target}

```text
타겟 종류:

1. arm-none-eabi (bare-metal)
   - 운영체제 없음
   - sys/socket.h 없음
   - RTOS/펌웨어용

2. arm-linux-gnueabihf (Linux)
   - Linux 운영체제
   - sys/socket.h 있음
   - 게이트웨이/서버용 ← 우리 프로젝트!
```

**교훈**:

> arm-none-eabi로 Linux 타겟 빌드 시도 → 실패 (sys/socket.h 없음) 반드시 arm-linux-gnueabihf 사용!


#### Prebuilt 라이브러리 ABI 호환성 {#prebuilt-라이브러리-abi-호환성}

**실패 사례**:

```text
librexbee.a: SigmaStar GCC 9.1.0으로 빌드
현재 컴파일러: GCC 14.3.0
→ dangerous relocation: unsupported relocation
→ 링크 실패!
```

**해결**:

> Prebuilt 라이브러리는 동일 컴파일러 버전 필요 → SigmaStar GCC 9.1.0 사용 필수 → 또는 소스코드로 재빌드


#### NixOS 특수성 {#nixos-특수성}

**문제**:

-   FHS 미지원 (Filesystem Hierarchy Standard)
-   `/bin/bash` 없음 → shebang 실패
-   일반 Linux 바이너리 실행 불가

**해결**:

1.  `pkgsCross` - NixOS 네이티브 크로스컴파일
2.  `buildFHSUserEnv` - FHS 환경 에뮬레이션
3.  Shebang: `#!/bin/bash` → `bash [script]` 직접 호출

### 🚨 중요 경고 {#중요-경고}


#### 1. Host Architecture 불일치 {#1-dot-host-architecture-불일치}

```text
❌ x86_64 컴파일러를 aarch64 서버에서 실행 시도
→ "cannot execute binary file: Exec format error"

해결: Host와 Target을 모두 고려한 컴파일러 선택
```


#### 2. bare-metal vs Linux 혼동 {#2-dot-bare-metal-vs-linux-혼동}

```text
❌ arm-none-eabi-gcc로 Linux 타겟 빌드 시도
→ "sys/socket.h: No such file or directory"

해결: Linux 타겟은 반드시 arm-linux-gnueabihf
```


#### 3. Prebuilt 라이브러리 ABI {#3-dot-prebuilt-라이브러리-abi}

```text
❌ GCC 9.1.0으로 빌드된 librexbee.a를 GCC 14.3.0으로 링크
→ "dangerous relocation: unsupported relocation"

해결: 동일 컴파일러 버전 사용 또는 소스 재빌드
```


#### 4. NixOS Shebang 문제 {#4-dot-nixos-shebang-문제}

```text
❌ #!/bin/bash
→ NixOS에 /bin/bash 없음

해결: bash [script] 직접 호출
```

### 🧠 학습 포인트 (Deep Insights) {#학습-포인트--deep-insights}


#### 1. 왜 grep은 근본적으로 한계가 있는가? {#1-dot-왜-grep은-근본적으로-한계가-있는가}

**grep의 본질**:

> grep = 정규표현식 기반 텍스트 매칭 코드의 구조(AST)를 이해하지 못함

**사례**:

```c
// 파일: src/mqtt_operations.c

/* mqtt_publish 함수 설명 */  ← grep이 이것도 찾음 (주석)
void mqtt_pub_message() {      ← 이것만 찾아야 함 (정의)
    char *msg = "mqtt_pub";    ← grep이 이것도 찾음 (문자열)
}

void another_func() {
    mqtt_pub_message();        ← 이건 호출 (정의 아님)
}

extern void mqtt_pub_message(); ← 이건 선언 (정의 아님)
```

**grep 결과**:

```text
4개 매칭 (주석, 정의, 문자열, 호출)
→ 에이전트가 수동으로 구분해야 함
→ 비효율!
```

**clang-query 결과**:

```text
1개 매칭 (정의만)
→ 100% 정확
→ 효율!
```


#### 2. 왜 빌드 없이 AST 분석이 가능한가? {#2-dot-왜-빌드-없이-ast-분석이-가능한가}

**CMake의 2단계**:

```text
1. Configure (설정 단계)
   → CMakeLists.txt 읽기
   → 컴파일 명령어 생성
   → compile_commands.json 생성  ← 여기까지만!

2. Build (빌드 단계)
   → 실제 컴파일
   → 링크
   → 바이너리 생성
```

**우리의 전략**:

> Configure 단계만 실행 → compile_commands.json 획득 → 2초 만에 완료 → clang-query로 즉시 분석 가능!


#### 3. 재현 가능한 환경이 왜 중요한가? {#3-dot-재현-가능한-환경이-왜-중요한가}

**시나리오**:

```text
팀원 A: Ubuntu 22.04, clang 14
팀원 B: Arch Linux, clang 18
팀원 C: NixOS, clang 19

→ 모두 다른 결과!
→ "내 환경에서는 되는데요?" 문제
```

**nix flake 사용 시**:

```text
flake.lock이 모든 버전 고정
→ 모두 동일한 clang 버전 사용
→ 동일한 결과 보장
→ 협업 효율 극대화
```


#### 4. 에이전트 친화적 도구란? {#4-dot-에이전트-친화적-도구란}

**Good Design**:

```bash
# 명확한 입력
./code-query.sh compile_commands.json function mqtt_pub

# 명확한 출력 (JSON 또는 구조화된 텍스트)
{
  "name": "mqtt_pub",
  "file": "src/mqtt_operations.c",
  "line": 127
}

# 빠른 실행 (<1초)
# 예측 가능한 동작 (멱등성)
```

**Bad Design**:

```bash
# 복잡한 옵션
./analyze.py --config config.yaml --output-format custom --filter "mqtt*" --recursive

# 불명확한 출력
"Found mqtt_pub somewhere in the code"

# 느린 실행 (>5초)
# 예측 불가 (상태 변경, side-effect)
```
